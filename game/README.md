# THE LAST LAMP: a game from *Never Say Your Name to the Wind*

| File | What it is |
|---|---|
| `GDD-The-Last-Lamp.md` | Game design document built on the course's five answers (WHO, WANTS WHAT, HOW YOU PLAY, WHERE AND WHEN, THE TWIST) |
| `Unreal-Build-Guide.md` | Step-by-step Unreal Engine 5 Blueprint plan for the team |
| `prototype/the-last-lamp.html` | A playable browser prototype (Three.js) for testing the idea before the Unreal build |

Prototype controls: **WASD** to move, **hold Space** to charge the Light and release to blast, **Shift** to dodge, **E** to make Ghareeb bark. On a phone: the left thumb is the joystick, and the buttons are on the right.
